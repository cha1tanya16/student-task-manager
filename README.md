# Student Task Management System

A simple task management web application developed as part of the Agile Tools Hack Lab for the subject Agile Software Development.

## Project Objective

The objective is to develop a basic web application that allows students to manage their tasks while practising Agile project management, Kanban workflow tracking and GitHub version control.

## Features

- **Add Task:** Create a new task.
- **View Task:** Display the list of tasks.
- **Complete Task:** Mark a task as completed.
- **Delete Task:** Remove an unwanted task.

## Technologies Used

- HTML
- CSS
- JavaScript
- Jira for Agile project and task tracking
- GitHub for version control
- GitHub Actions for basic automated checks (planned)
